＋Supported versionsJava 17/21 · Tomcat 10.x

Universal Controller runs on Java 17 or Java 21 (headless recommended) with Apache Tomcat 10.x.

＋Tomcat: package vs tar.gzwhy manual on RHEL

No Tomcat 10 package is published for RHEL/CentOS or Amazon Linux 2023, so the manual tar.gz path is selected automatically there. Ubuntu/Debian ships tomcat10 via apt.

＋Harden permissionsoptional

By default the whole Tomcat directory is handed to the Tomcat user. With this option, root takes back bin/, lib/ and conf/, so a compromised Tomcat cannot rewrite its own startup scripts, drop a jar or edit server.xml. The install root itself stays owned by the Tomcat user because Universal Controller creates uc_logs/ and uc_export/ underneath it, and logs/, temp/, work/ and webapps/ stay writable by inheritance.

＋JVM memory (setenv)Xms 512m

Choosing a heap size writes a setenv.sh in the Tomcat bin/ directory that sets CATALINA_OPTS. Default leaves Tomcat's built-in settings alone. See the Sizing Calculator for heap sizing guidance. The file is written with sudo sh -c because the manual install has already handed that directory to the Tomcat user — a plain redirect would fail with "Permission denied", and so would sudo cat >, since the redirection still runs in your own shell.

＋systemd service filemanual installs only

Only needed for tar.gz installs — package installs register their own unit. JAVA_HOME is optional; leave it blank to get a commented-out placeholder. Run systemctl daemon-reload after copying the file.

＋DatabaseMySQL · MariaDB · Postgres

The generator scripts MySQL, MariaDB and PostgreSQL. Oracle and SQL Server are supported by the Controller but must be prepared by hand — follow the Stonebranch Database Installation Guide.

＋Agent prerequisitesextra libraries

Universal Agent needs a few system libraries: libxcrypt-compat on Amazon Linux/RHEL. Install them before running the agent installer.
